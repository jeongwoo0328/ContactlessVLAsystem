해당 코드는 크게 3가지 부분으로 분류 할 수 있습니다.
1. main.py
2. memory_manager.py
3. perception_core.py
4. phi_reasoning_module.py(코드에는 phi-3 mini가 아닌 Qwen2.5 1.5B 모델이 있음)
5. pybullet_module.py & robot_geometry.py
6. semantic_analyzer.py
